# Private Client-Side PDF & Image Toolkit

A privacy-first PDF and image toolbox built with Next.js 14. Files are processed entirely in the browser with `pdf-lib`; they are not uploaded to an application server.

## Tools

- Merge multiple PDFs and reorder them before export
- Extract custom page ranges such as `1-3, 5`
- Convert ordered JPG and PNG images to fitted A4 PDF pages
- Remove common document metadata and repack PDF object streams

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Verification

```bash
npm run typecheck
npm run build
node --experimental-strip-types work/test-pdf-engine.ts
```

The browser-side engine test covers merge, page extraction, image conversion, range parsing and metadata cleaning.

## Privacy model

The app has no upload API. Selected files live in the current browser session and are passed directly to `pdf-lib`; generated bytes are downloaded with a temporary local object URL.

Large files are constrained by the memory available to the browser. The compression tool performs structural repacking and metadata cleanup; it does not downsample embedded images, so output size can vary by document.
